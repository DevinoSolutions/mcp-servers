# Listing logos

Square logos on a solid background plate, one per Devino MCP server, for marketplace forms that reject transparent logos (the Grok Bot marketplace asks for "1:1 SVG or PNG with a background plate").

- The 14 PNGs with a plugin folder are `<app>/assets/logo.png` flattened onto its own corner colour (Sendly onto its cream, #F6F1E7) at 512x512.
- `marka.png` is the App Store icon. `safemeet.svg` and `demofy.svg` are each app's own `icon.svg`, which already sits on a tile.

Link them from jsDelivr: `https://cdn.jsdelivr.net/gh/DevinoSolutions/mcp-servers@main/assets/listing-logos/<app>.png`
